プライバシーポリシー

2026年10月16日施行

要点。Pagegloss には、アカウントも広告も分析もトラッキングもありません。開発者が、あなたの書類、画像、メモ、ハイライト、保存した単語、調べた単語を受け取ることはありません。

iPad にとどまるもの

書類、画像、メモ（入力したものと手書き）、ハイライト、しおり、保存した単語、読んでいた位置、設定は、iPad にだけ保存されます。追加した API キーは iPad のキーチェーンに保存されます。アプリを削除すると、これらのデータも削除されます。

iPad 上で動作するもの

Apple の翻訳、iPad に内蔵された辞書、発音、画像やスキャンのテキスト認識、手書き文字の読み取り、iPad が対応している場合の Apple Intelligence による説明、読み上げは、すべてデバイス上で動作します。これらのために何かが送信されることはありません。

カメラと写真

Pagegloss がカメラを使うのは、ページを撮影するために「カメラでスキャン」を選んだときだけです。また、写真アプリやファイルアプリからあなたが選んだ画像だけを開きます。それらは iPad にとどまります。

iPad の外に出る可能性があるもの（あなたが選んだ場合のみ）

  • あなたが選んだオンライン翻訳サービス。Google、OpenAI、Gemini、DeepSeek などのサービスを選んだ場合、選択したテキスト、そのまわりの文または段落、言語の設定が、あなた自身のキーを使って iPad からそのサービスへ直接送られます。私たちのサーバーを経由することはありません。そのサービスは、送られたテキストを自社のプライバシーポリシーに従って扱い、一定期間保管することがあります。何かが送信される前に、サービスごとに許可を求められます。いつでもオフにできます。書類、メモ、ハイライトが送信されることはありません。
  • あなたが選んだオンラインのテキスト認識サービス。初期設定では、テキストは iPad 上で読み取られます。「設定 › OCRサービス」で Google Cloud Vision、Azure AI Vision、Mistral、Anthropic Claude、Gemini、OpenAI などのオンラインサービスを選んだ場合、読み取りを依頼したボックスの画像が、そのボックスだけ、あなたが依頼したときにだけ、あなた自身のキーを使って iPad からそのサービスへ直接送られます。事前に、サービスごとに許可を求められます。
  • 接続テスト。「接続をテスト」は決まった例文をひとつ送ります。「読み取りをテスト」は、iPad 上で作成した「Pagegloss reads boxes」という文字の小さな画像を 1 枚送ります。
  • タップしたリンク。画像の中の Web アドレス、電話番号、メールアドレスをタップすると、ふだんそれに使うアプリで開きます。

購入

アプリ内でアンロックを購入した場合、支払いは Apple が処理します。私たちがあなたの支払い情報を見ることはありません。

お子様について

Pagegloss は読書のためのツールであり、13歳未満のお子様を対象としたものではありません。

あなたが選べること

「設定」で、保存したキーを削除したりオンラインサービスをオフにしたりできます。また、書類やメモを個別に削除することも、アプリを削除してすべてを消去することもできます。

変更について

このポリシーを変更した場合は、新しい施行日とともに、新しい版をこのアドレスに掲載します。
